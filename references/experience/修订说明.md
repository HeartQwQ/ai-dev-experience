## 二、保留与重组的主要经验

- 后端覆盖分层、请求、状态、PostgreSQL/SQLite 与零停机迁移、异步取消、RFC 9457 错误、OpenTelemetry 观测、Contract-First 契约、文件/远端写入、锁、缓存、性能和测试。
- 前端覆盖 Svelte 5 Runes 响应式、作用域、契约消费与解码、竞态、部署路由、CSP 与 Tauri v2 最小权限安全、缓存、组件、列表、表单、Biome/Vitest Browser Mode 质量验收、文案与教程。
- 资产篇管理外部 Skill 追溯、Plugin/Hooks 系统级门禁、前端/Rust 现代工具链约定、专项审查与去重评测。
- 工程篇覆盖多层版本锁定（`mise` / `catalog:` / `rust-toolchain` / `deny.toml`）、任务分级、双图谱与 Hook 门禁、检查矩阵、双栈实例管理、备份一致性与发布回滚。
- UI 篇覆盖信息层级、Tailwind v4 OKLCH 语义 token、状态、组件、`@container` 容器查询布局、WCAG 2.2 可访问性（含 ≥ 24×24px 目标尺寸与焦点外观）及可选桌面密集工具预设。
