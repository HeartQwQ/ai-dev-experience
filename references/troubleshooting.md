# 环境搭建常见问题

先保留失败命令、退出码、工作目录、实际工具版本和受控错误摘要。`dev.py` 启动失败会自动附上对应服务日志的最后 30 行。一次只改变一个可验证因素，不能反复重装、清缓存或换端口碰运气。

| 现象 | 先确认什么 | 处理与边界 |
| --- | --- | --- |
| 工具已装却找不到 | 当前 shell PATH、`mise` 激活状态、安装目录、真实解释器/OS | 开新终端或使用已确认绝对路径；避免 WindowsApps 空启动器 |
| Windows 脚本不能执行 | 调用的是 `.ps1`、`.cmd` 还是 exe，当前执行策略 | 使用该工具正常支持的可执行入口；不全局放宽策略 |
| 依赖下载失败 | 官方源、代理、证书、DNS、锁文件和权限 | 修配置或使用受控缓存；不关闭 TLS 校验 |
| pnpm 全局安装失败 | `PNPM_HOME`/global bin 是否配置、当前版本安装方式 | 按实际版本文档设置用户级环境，不引入第二套混乱管理器 |
| 刚发布稳定版不能解析 | pnpm 当前的发布年龄、构建脚本与信任策略，或 `catalog:` 写法 | 查选定版本文档，记录等待或兼容版本选择，不一键禁用全部保护 |
| peer/engine 冲突 | 最新 Kit/Vite/Svelte 5/Tailwind v4/UI/Node 是否同一支持矩阵 | 用最新兼容稳定组合并锁定至 `pnpm-workspace.yaml` 的 `catalog:`，不强制忽略 peer 继续 |
| 原生模块或 Rust 链接失败 | OS/CPU、MSVC/SDK 或平台依赖、目标三元组 | 安装真正缺的工具；后端能在 WSL 编译不代表 Windows Tauri 可打包 |
| `cargo deny check` 报错 | 许可证未列入 `deny.toml` 白名单、存在 RustSec 漏洞或重复依赖 | 核实上游许可证合规性后显式更新 `deny.toml` 或升级漏洞依赖，不盲目关闭检查 |
| Tauri v2 白屏或权限拒绝 | `frontendDist`/`devUrl`、静态产物、SSR 与 `src-tauri/capabilities/` 权限配置 | 对照 Tauri v2 文档配置静态前端与最小权限 capability，不开通配符全权限 |
| 前端能开 API 不通或类型错配 | 实际服务地址、代理、CORS、认证，以及 `utoipa`/`tauri-specta` 契约是否重新生成 | 分层验证并重新生成契约客户端，不手改生成产物掩盖错误 |
| 图谱零节点/缺符号 | 语言/扩展、真实应用是否存在、忽略与解析摘要 | 修覆盖并重建，不能把零节点当通过 |
| 软链或大文件阻断图谱指纹 | 符号链接是否指向仓库外部，或源码目录混入 >32 MiB 数据文件 | 仓库内合法软链已支持自动解析；移除越界软链或将大体积数据移出源码目录并加入忽略 |
| graphify 包名装错 | 官方包 `graphifyy`，命令 `graphify` | 核实来源和版本，不使用近似名称替代 |
| graphify 想调用模型 | `--code-only`、`GRAPHIFY_BACKEND=none` 和继承配置 | 固定本地 `none` 后端并关闭语义模式，拒绝云端回退 |
| 网状图离线打不开 | `graph.html` 引用、`vendor/` 完整性、SRI 与 `.source.json` 哈希 | 本地化已核实渲染依赖；缺缓存时阻断，不保留 CDN 回退 |
| Hook 拦截 `PreToolUse` 拒绝读码 | `dev-spec.project.json` 是否已处于 `READY` 但未跑 `graph_gate.py build/query` | 先执行 `graph_gate.py build` 与 `query` 使指纹同步，禁止绕过或删除 `.agents/hooks.json` |
| CodeGraph 锁/Transport closed | 同仓多个写者、daemon、网络盘、WSL `/mnt` | 先确认进程与文件系统；按上游支持隔离索引/使用本地盘，不擅删活锁 |
| 切分支后图谱仍旧 | 源指纹、工具版本、图谱根和自动同步 | 重新构建/同步并实际查询；旧缓存不能证明当前分析 |
| 预览端口占用（含 IPv4/IPv6） | `127.0.0.1` 或 `::1` 上的占用者是否本项目、本用户、当前启动拥有 | 不杀未知进程；停已授权实例或明确更新配置/地址 |
| Windows 端口无监听仍报 WinError 10013 | 系统保留端口范围（`netsh interface ipv4 show excludedportrange protocol=tcp`）、权限与最近退出实例 | 先查真实原因；必要时明确调整开发配置并同步地址，不以静默换端口或关闭防护处理 |
| 一键预览立即失败 | 是否还在 `BOOTSTRAP`、必需应用清单、dev 命令、就绪接口及日志尾部报错 | 根据控制台自动输出的最后 30 行服务日志定位根因；不以跳过门禁让空骨架假成功 |
| 数据库认证/迁移失败 | 开发连接、实例/库/账号、权限、`sqlx` 迁移版本与离线元数据 | 使用隔离测试库查问题，不在生产上试清库或重建 |

仍不能解决时，报告准确阻塞层级和已完成的独立工作。图谱与 Hook 硬门禁没有自行降级分支：不能用纯搜索继续依赖代码分析的业务开发。
